Live simulator in CLion (Wokwi plugin)

  1. Install the Wokwi plugin in CLion and activate it (Wokwi: Request a new license, free; this is separate from the CI token above).
  2. Open this folder as the project. Build the firmware once: Terminal, pio run (or the Tests tab, "Build firmware").
  3. Open diagram.json to see the board, or choose Start Simulator from the plugin menu / Wokwi tool window. It reads wokwi.toml, which points at .pio/build/esp32-c3-devkitm-1/firmware.elf and the two custom chips in chips/.
  4. In the simulator, set the MPU6050 accelZ slider to 3.0 or more for a second: the OLED shows ALERT SENT, the LED lights and the buzzer sounds. The packet appears in the serial monitor.
  5. To try the voice modem, paste the line from ptt_sample_line.txt into the serial monitor input: the OLED shows VOICE TX and the buzzer stays silent.

I could not run the CLion plugin myself; the steps follow Wokwi's documented project layout. If the plugin does not pick the project up, the same files work in the Wokwi VS Code extension.
